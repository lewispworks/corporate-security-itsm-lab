# Corporate Security & ITSM Laboratory

## Objective

Build and document a small enterprise security laboratory demonstrating:

- Linux system hardening
- Network segmentation
- Docker security
- Access control
- Linux ACLs
- Security testing
- IT service management
- Just-in-time access
- Audit logging
- Access revocation
